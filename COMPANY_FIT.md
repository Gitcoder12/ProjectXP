# ProjectXP — Company and Team Fit

These are potential skills and employer matches, not claimed product use or endorsement.

## Project thesis

A simple browser project tracker where you add projects, record features and see progress in one place.

## GitHub

**Relevant technical areas:** Developer experience, project tracking and open-source collaboration.

**Potential roles:** Frontend Engineer, Product Engineer, Developer Tools Engineer or Full-stack Engineer.

**Evidence to build:** A static single-page HTML/CSS/JavaScript application. Project and feature records are saved in browser localStorage. It supports progress percentages, repository/demo URLs, feature states and bundled examples. Local browser storage is not multi-user sync or a server backup.
