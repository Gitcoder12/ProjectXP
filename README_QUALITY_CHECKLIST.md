# ProjectXP — README Quality Checklist

- [ ] A beginner can create a project and update feature status.
- [ ] README tells where data is stored and how it can be lost.
- [ ] Technical section explains state, progress calculation and storage schema.
- [ ] Input validation, import/export and migration behavior are documented.
- [ ] No claim of sync or backup is made without implementation.
- [ ] Roadmap, activity log, company fit and contribution guide are linked.
